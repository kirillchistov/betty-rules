# Свой курс

Место для своих затей. Не учёба, не правила «как правильно жить» и не контрольная.

В браузере: короткий онбординг, шесть установок, которые можно переименовать и не принять, три готовые истории и три пустые темы, свои записи. Всё хранится локально в этом браузере. Между устройствами данные переносятся только файлом выгрузки из настроек.

## Локально

Нужен Node.js.

```bash
make install
make dev
```

На этом компьютере: http://127.0.0.1:5173/ . С телефона в той же сети подойдёт сетевой адрес, который напишет Vite.

```bash
make build     # проверка типов и сборка в dist/
make preview   # посмотреть собранный сайт
make clean     # удалить dist/
```

## GitHub Pages

Сайт статический. Адреса относительные, экраны открываются через `#`, поэтому отдельный сервер не нужен. После выкладки страница доступна с любого устройства по ссылке вида:

`https://<логин>.github.io/<репозиторий>/`

На бесплатном плане страница публикуется из публичного репозитория.

1. Залить проект на GitHub, ветка `main`.
2. В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Запушить в `main`. Workflow `.github/workflows/pages.yml` соберёт `dist` и выложит его.
4. Ссылка появится в запущенном workflow и в Settings → Pages.

Записи, названия и тема на телефоне будут свои: это память того браузера, а не общая база.
